# HBM Far View

Addon for NTM - Continuum (Minecraft 1.21.1, NeoForge). Keeps the mushroom cloud, the large blast effects and NTM missiles visible from far away, beyond the render distance. Optional support for Distant Horizons 3.3.3.

Download: CurseForge, project "HBM Far View".

## Building
1. Install JDK 21.
2. Open the folder in IntelliJ IDEA (File > Open, select `build.gradle`, Open as Project) and wait for Gradle to load.
3. Run the Gradle task `build`.
4. The jar is in `build/libs`.

`libs/distanthorizons-api-3.3.3.jar` is the Distant Horizons API (LGPL-3.0), used only at compile time.
